# ExameSaver

Приложение для **Mi Band 7 (Zepp OS 1.0)**: читалка текстовых заметок и просмотр фото из веб‑галереи. Всё сохраняется в память часов и работает без телефона.

## Состав проекта
| Часть | Где | Что делает |
|---|---|---|
| Часы | `page/`, `utils/`, `app.js`, `assets/` | список заметок, читалка, размер шрифта, раздел «Фото», просмотр с плитками |
| Телефон (Zepp) | `app-side/`, `setting/` | сервис связи с часами, страница настроек в Zepp: заметки для передачи, адрес и токен моста |
| Мост галереи | `tools/gallery_bridge.py` | Python + Pillow: читает галерею, сжимает под экран часов, отдаёт кусками base64 |
| Общее | `shared/` | MessageBuilder, работа с файлами |

## Возможности
- **Заметки:** синхронизация с телефоном кнопкой, оффлайн‑чтение, удаление, размер шрифта. Лимит 30 файлов по 20 000 символов.
- **Фото (1.1.0):** синхронизация из галереи через мост, серые или цветные, до 12 фото; длинные картинки режутся на экраны (до 4), широкие поворачиваются автоматически; экран «Проверка показа фото» подбирает рабочий путь к файлу.

## Как работают фото
Часы не качают картинки сами, а сервис на телефоне получает только текст/JSON. Цепочка:

`галерея → gallery_bridge.py → сервис в Zepp (прокси) → часы (base64 → файл в формате TGA → виджет IMG)`

Мост отдаёт `/list`, `/meta`, `/chunk` (JSON), токен передаётся заголовком `X-Token`.

## Запуск моста
```
pip install pillow
python3 tools/gallery_bridge.py --gallery http://ваш-сервер/gallery/ --token секрет
# локальная папка: --dir ~/Pictures
# закрытый сервер: --header "Authorization: Bearer ..."
```
На телефоне (Termux) адрес `http://127.0.0.1:8765`; на ПК в той же Wi‑Fi сети — `http://IP-ПК:8765`. Адрес и токен вводятся в настройках приложения в Zepp.

## Сборка и установка
```
npm i -g @zeppos/zeus-cli
zeus login
zeus dev            # симулятор
zeus preview        # QR для часов
zeus build          # .zab в dist/
```
Целевое устройство: `band-7` (в патченом Zepp отображается как Amazfit Band 7), экран 192×490.

## Использование
1. Синхронизация на главном экране: заметки загрузятся в память часов.
2. Строка «Фото · N» → синхронизация → тап по фото. Тап справа/слева листает части длинной картинки.
3. «...» справа сверху: размер шрифта, режим фото (серые/цветные), проверка показа.

## Что не проверено на устройстве
- показ картинок из каталога данных приложения на API 1.0 (запасной вариант: экран «Проверка показа фото»);
- HTTP без шифрования от приложения Zepp к мосту;
- скорость передачи по Bluetooth (одно фото около 50–100 КБ).
